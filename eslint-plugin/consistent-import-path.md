# consistent-import-path

`src` 直下の同じディレクトリ配下にあるモジュール同士のインポートは相対パス
（`./`、`../`）に、それ以外は `@/` の絶対パスに統一します。

- 同じディレクトリ: `./foo`
- `src` 直下の同じディレクトリ配下: `../bar/foo`
- `src` 直下のディレクトリをまたぐ場合: `@/foo/bar`

例えば `src/components` から `src/store` へのインポートは `@/store` になります。

`src` 直下のディレクトリ単位で「同じ概念」とみなすことで、ディレクトリ構成の
変更時にも壊れにくい相対インポートを保ちつつ、概念をまたぐ参照は常に `@/` に
統一できます。
